# 🚀 FoodSwipe - Quick Start Guide

Welcome to FoodSwipe! Here's how to run your app.

## Simplest Way to Run

```bash
npm run dev
```

This shows you a menu to choose where to run the app.

---

## Run on iOS Simulator (Recommended)

```bash
npm run simulator
```

Opens the app in iPhone Simulator on your Mac. Fast and perfect for development!

---

## Run on Your Phone

### Same WiFi Network:
```bash
npm run phone
```

### Cellular Data / Any Network:
```bash
npm run phone:tunnel
```

Then scan the QR code with Expo Go app.
